### Research

- **TÜBİTAK 2209-A undergraduate research project (2023–2024)**: *Brand preference and loyalty*. Project lead.
  Survey design and data collection ($N = 407$); normality checks, Spearman correlations, $\chi^2$ tests of
  independence, and ANOVA with Tukey's HSD.
- **International Data Science and Statistics Congress (IDSSC 2024)**: oral presentation. Multi-class random forest
  classification on imbalanced data with SMOTE resampling.
- **V. International Applied Statistics Congress (UYIK 2024)**: proceedings paper. Consumer preferences analysed with
  two-sample tests and correlation analysis.

### Selected repositories

I am revising my earlier projects one by one. Each revised repository has unit tests, fixed seeds, figures and tables
generated by the code, and a short project note. `NEWS.md` lists what was corrected relative to the first version,
which is kept as the `v1.0.0` release.
